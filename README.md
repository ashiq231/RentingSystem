# Renting System

A web-based Renting System designed to simplify the process of managing rental properties, tenants, bookings, and payments. The platform provides an efficient solution for property owners and renters by streamlining rental operations through a user-friendly interface.

## 🚀 Features

* User Authentication & Authorization
* Property Listing Management
* Tenant Registration
* Rental Booking System
* Property Search & Filtering
* Booking History
* Admin Dashboard
* Responsive User Interface
* Secure Database Management

## 🛠️ Technologies Used

### Backend

## ⚙️ Installation

### Prerequisites

* XAMPP / WAMP
* PHP 7.4+
* MySQL

### Steps

1. Clone the repository

```bash
git clone https://github.com/ashiq231/RentingSystem.git
```

2. Move the project folder to your web server directory.

For XAMPP:

```text
htdocs/
```

3. Create a MySQL database.

4. Import the SQL file into MySQL.

5. Update database credentials in the configuration file.

```php
$host = "localhost";
$user = "root";
$password = "";
$database = "renting_system";
```

6. Start Apache and MySQL.

7. Open your browser and visit:

```text
http://localhost/RentingSystem
```
